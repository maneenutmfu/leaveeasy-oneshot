## ⚠️ ตอนนี้ระบบยังไม่มีความจำ

ลองเปิด **ยื่นใบลาใหม่** → กรอกอะไรก็ได้ → กดบันทึก → **กด F5 รีเฟรช**
ข้อมูลที่เพิ่งกรอกจะหายหมด เพราะข้อมูลทั้งหมดยังเป็นของปลอมที่พิมพ์ค้างไว้ใน `js/data.js`

**นั่นคือสิ่งที่คุณจะแก้ในสัปดาห์ที่ 6** — ต่อระบบเข้ากับคลังเก็บข้อมูลจริง

---

## 🔥 ตั้งค่า Firebase (สัปดาห์ที่ 6)

1. สร้างโปรเจกต์ที่ [Firebase Console](https://console.firebase.google.com) แล้วเปิดใช้ **Firestore Database**
2. เปิด **Project settings → General → Your apps** คัดลอกค่า `firebaseConfig` มาใส่ใน `js/firebase-config.js` แทนของเดิม
3. เปิด **Firestore Database → Rules** คัดลอกเนื้อหาจากไฟล์ `firestore.rules` ในโฟลเดอร์นี้ไปวางแล้วกด Publish
   (กฎนี้เปิดอ่าน/เขียนแบบไม่ล็อกอินไปก่อน เพราะสัปดาห์ที่ 6 ยังไม่มีระบบล็อกอิน — จะรัดกุมขึ้นในสัปดาห์ที่ 7–8)
4. เปิดหน้า `seed.html` ในเบราว์เซอร์ แล้วกด **"เริ่มใส่ข้อมูลตัวอย่าง"** ครั้งเดียว เพื่อคัดลอกข้อมูลปลอมจาก `js/data.js` ขึ้น Firestore
5. เปิด `leave-requests.html` — ตารางใบลาจะอ่านข้อมูลจริงจาก Firestore แล้ว ลองแก้ข้อมูลใน Firebase Console แล้วรีเฟรชหน้านี้ดู ค่าจะเปลี่ยนตาม

> 📌 สัปดาห์ที่ 6 ต่อ Firestore แบบ **อ่านอย่างเดียว** เฉพาะหน้ารายการใบลา — หน้ายื่นใบลาใหม่ / รายละเอียด / ประเภทการลา ยังใช้ข้อมูลปลอมเหมือนเดิม จะเปลี่ยนเป็นบันทึกจริงในสัปดาห์ที่ 7

## 🗓️ 4 สัปดาห์นี้คุณจะทำอะไรกับมัน

| สัปดาห์ | สิ่งที่ระบบจะทำได้เพิ่ม |
|:-:|---|
| **6** | เก็บข้อมูลลงคลังจริง · หน้ารายการอ่านจากคลัง ไม่ใช่ข้อมูลปลอม |
| **7** | เพิ่ม แก้ ลบ ได้จริง · ล็อกอิน · ขึ้นออนไลน์ให้คนอื่นเปิดได้ |
| **8** | ปิดข้อมูลไม่ให้คนอื่นอ่านของเรา · ใส่ปุ่มผู้ช่วย AI |
| **9** | ให้ AI ทดสอบระบบแทนเรา · เก็บของส่งมอบ |

**ใบงานของแต่ละสัปดาห์จะพาทำทีละขั้น** — ไม่ต้องทำล่วงหน้า และไม่ต้องเดาเอง
